# Redmine Helper — 제품 요구사항 문서 (PRD)

**버전**: 1.0
**작성일**: 2026-03-13
**상태**: 초안

---

## 1. 제품 개요

### 1.1 목적

Redmine Helper는 Redmine 이슈 등록 시 기존 이슈를 자동 분석하여 유사 이슈 목록과 AI 요약 답변을 제공하는 **이슈 자동화 도우미**입니다.
새 이슈가 등록되는 순간 Redmine 웹훅을 통해 이벤트를 감지하고, 기존 이슈 및 댓글/해결책을 검색하여 Claude API로 핵심 해결 방법을 요약한 뒤 해당 이슈에 자동으로 댓글을 달아줍니다.
최종 목표는 **Redmine 이슈 처리 자동화**로, 반복 이슈 대응 시간을 줄이고 팀 지식을 재활용하는 것입니다.

### 1.2 배경 및 문제 정의

- 동일하거나 유사한 이슈가 반복 등록되어 담당자가 매번 같은 답변을 작성합니다.
- 기존에 해결된 이슈의 해결책이 묻혀 재활용되지 않습니다.
- 새 이슈가 어떤 카테고리인지, 누가 담당해야 하는지 판단하는 데 시간이 걸립니다.
- 중복 이슈가 걸러지지 않아 관리 비용이 증가합니다.

### 1.3 제품 목표

- 새 이슈 등록 즉시 유사 이슈를 자동 검색하고 AI 요약을 댓글로 제공
- 이슈 자동 분류/태깅으로 카테고리 분류 자동화
- 중복 이슈 감지 및 경고
- 웹 대시보드에서 분석 결과 및 이력 확인

## 4. 핵심 기능 요구사항

### 4.1 이슈 자동 감지 및 유사 이슈 검색

**목적**: 새 이슈 등록 시 즉시 관련 기존 이슈를 찾아 담당자에게 제공

**동작 흐름**:
```
Redmine 새 이슈 등록
  → 웹훅 이벤트 수신 (FastAPI)
  → 이슈 제목/설명으로 기존 이슈 검색 (Redmine REST API)
  → 유사도 계산 및 상위 N개 추출
  → Claude API로 해결책 요약 생성
  → 원본 이슈에 댓글 자동 작성
```

**검색 대상**:
- Redmine 기존 이슈 (제목, 설명)
- 이슈에 달린 댓글 (특히 해결 내용 포함된 댓글)

**수용 기준**:
- 새 이슈 등록 후 2분 이내에 유사 이슈 댓글이 작성된다.
- 유사 이슈가 없을 경우 댓글을 작성하지 않는다 (임계값 이하).
- 유사도 상위 최대 5개 이슈가 댓글에 링크와 함께 표시된다.

---

### 4.2 AI 요약 및 댓글 자동 작성

**목적**: 유사 이슈의 해결책을 Claude API로 요약하여 즉시 활용 가능한 답변 제공

**기능 상세**:
- 검색된 유사 이슈의 댓글/해결책을 Claude API에 전달
- Claude가 핵심 해결 방법을 한국어로 요약 생성
- 요약 내용 + 유사 이슈 목록을 새 이슈의 댓글로 자동 등록
- 댓글 형식: AI 요약 안내 문구 + 해결 방법 요약 + 참고 이슈 링크 목록

**댓글 예시 형식**:
```
[Redmine Helper 자동 분석]

유사한 기존 이슈를 발견했습니다. 아래 내용을 참고해 주세요.

■ 해결 방법 요약
(Claude가 생성한 요약 내용)

■ 참고 이슈
- #123 이슈 제목 (유사도: 92%)
- #87 이슈 제목 (유사도: 78%)
```

**수용 기준**:
- 요약 내용이 참고 이슈의 실제 해결 내용을 반영한다.
- 댓글에 AI 생성임을 명시하는 문구가 포함된다.
- Claude API 호출 실패 시 유사 이슈 목록만 댓글로 작성한다.

---

### 4.3 이슈 자동 분류/태깅

**목적**: 이슈 내용을 분석하여 카테고리/태그를 자동으로 부여

**기능 상세**:
- 새 이슈의 제목과 설명을 분석하여 미리 정의된 카테고리로 분류
- 분류 결과를 Redmine 이슈의 커스텀 필드 또는 태그에 자동 반영
- 카테고리 목록은 설정 파일(`.env` 또는 관리 UI)에서 관리

**수용 기준**:
- 이슈 등록 후 자동으로 카테고리가 지정된다.
- 분류 신뢰도가 낮을 경우 태깅하지 않고 대시보드에 검토 항목으로 표시한다.

---

### 4.4 중복 이슈 감지

**목적**: 이미 등록된 이슈와 동일한 이슈가 중복 등록되는 것을 방지

**기능 상세**:
- 유사도가 설정 임계값(기본 90%) 이상인 이슈가 존재하면 중복 경고 댓글 작성
- 중복 의심 이슈와의 링크를 댓글에 포함
- 대시보드에서 중복 감지 이력 확인 가능

**수용 기준**:
- 유사도 90% 이상 이슈 존재 시 "중복 이슈 의심" 댓글이 작성된다.
- 중복 여부는 사용자가 최종 판단 (자동 닫기 없음).

---

### 4.5 웹 대시보드

**목적**: 자동 분석 결과 및 이력을 시각적으로 확인

**기능 상세**:
- 최근 처리된 이슈 목록 및 분석 결과 확인
- 유사 이슈 검색 결과 및 AI 요약 이력 조회
- 중복 감지 이력 확인
- 이슈 분류 통계 (카테고리별 이슈 수, 중복 감지 수 등)
- 수동 재분석: 특정 이슈를 선택하여 분석 재실행

**수용 기준**:
- 대시보드에서 최근 100건의 분석 이력이 표시된다.
- 각 이력에서 원본 이슈 링크, 유사 이슈 목록, AI 요약 내용을 확인할 수 있다.

## 5. 인증

### 5.1 Redmine 연동 인증

- Redmine API Key를 환경 변수로 설정 (`.env` 파일)
- 웹훅 수신 시 시크릿 토큰으로 요청 유효성 검증
- 댓글 작성은 설정된 Redmine 계정(봇 계정 권장)으로 수행

### 5.2 대시보드 접근

- 단순 비밀번호 인증 (팀 내부 접근용)
- 별도 회원 관리 없음

## 6. 비기능 요구사항

### 6.1 성능

- 웹훅 수신 후 댓글 작성까지: 2분 이내
- 유사 이슈 검색: 30초 이내
- Claude API 요약 생성: 30초 이내 (타임아웃 설정)

### 6.2 확장성 및 운영

- 지원 프로젝트 수: 최대 30개
- 분석 이력 저장: SQLite
- 실행: `docker compose up`으로 단일 명령 배포
- Claude API Key, Redmine URL, API Key는 `.env`로 관리

### 6.3 보안

- Redmine API Key 및 Claude API Key는 서버 환경 변수로만 관리
- 웹훅 요청은 시크릿 토큰으로 검증
- 대시보드는 팀 내부 네트워크에서만 접근

### 6.4 유지보수

- 유사도 임계값, 최대 참고 이슈 수, 카테고리 목록은 설정 파일로 관리
- 분석 실패 시 에러 로그 기록 및 대시보드에 실패 항목 표시

## 7. 엣지 케이스 및 제약사항

### 7.1 Claude API 장애

- API 호출 실패 시 유사 이슈 목록만 댓글로 작성 (요약 없이)
- 재시도 1회 후 실패 시 에러 로그 기록

### 7.2 유사 이슈 없음

- 유사도 임계값 이하인 경우 댓글 미작성
- 대시보드에는 "유사 이슈 없음"으로 기록

### 7.3 Redmine 웹훅 미지원 버전

- 웹훅을 지원하지 않는 Redmine 버전의 경우 폴링 방식으로 대체 (설정으로 전환)
- 폴링 주기: 1분

### 7.4 대용량 이슈 데이터

- 검색 대상 이슈가 많을 경우 최근 1년치 이슈로 범위 제한 (설정 가능)
- 이슈 내용이 너무 길 경우 앞 2000자만 Claude API에 전달

### 7.5 반복 댓글 방지

- 동일 이슈에 Redmine Helper 댓글이 이미 존재하면 재작성하지 않음
- 수동 재분석 시에는 기존 댓글을 업데이트
